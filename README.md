# 校园网自动登录助手（仅使用于巢湖学院）
这是一个旨在简化和自动化校园网登录过程的实用工具。它通过后台静默执行浏览器操作，自动填充并提交您的登录凭据，让您开机即用网络，无需每次手动打开登录页面。

## 第一部分：功能介绍

本项目包含两个核心组件：

1.  **图形化配置工具 (AutoHotkey)**：
    * 提供一个简洁的图形界面，让用户可以轻松输入并保存自己的校园网账号、密码和运营商信息。
    * 配置信息会以 `config.json` 的格式保存在本地，安全且方便管理。
    * 启动时会自动读取现有配置，方便用户修改。

2.  **自动登录脚本 (Python)**：
    * 核心的登录执行程序，使用 Playwright 库驱动一个无头浏览器 (Headless Microsoft Edge) 在后台运行，用户无感知。
    * 启动时会自动读取 `config.json` 文件中的配置信息。
    * **智能检测**：在执行登录前，会先访问登录页面并检查是否已经处于登录状态。如果已登录，则会跳过操作，避免重复登录。
    * 自动填写账号、密码，并根据配置选择正确的运营商。
    * 自动点击登录按钮，完成整个登录过程。
    * **可被计划**：该脚本可以被设置为开机自启动实现全自动登录。

## 第二部分：部署文档

我们提供两种使用方式：直接运行打包好的程序（推荐）或自行从源码部署。

### 1. 使用已打包的 EXE 文件（推荐）

对于大多数用户，我们建议直接从 Release 页面下载打包好的可执行文件，这是最简单快捷的方式。

* **下载**：请前往本仓库的 **[Releases](https://github.com/sep-zxy/Auto-login-on-campus-network/releases)** 页面，下载最新的压缩包。通常你会得到两个文件：
    * `配置工具.exe` (config_ui.exe)
    * `自动登录.exe` (autologin.exe)
    * `开机启动管理.bat`

* **步骤一：配置你的登录信息**
    1.  双击运行 `配置工具.exe`。
    2.  在弹出的窗口中，输入你的校园网 **账号** 和 **密码**。
    3.  **运营商** 字段默认是 `巢湖学院`，如果你的学校名称不同，请修改为你在登录页面选项框中看到的全称。
    4.  点击 **“保存配置”** 按钮。程序会提示保存成功，并在同目录下生成一个 `config.json` 文件。

* **步骤二：执行登录**
    1.  直接双击运行 `自动登录.exe`。
    2.  程序会在后台静默执行登录操作。如果一切顺利，你将很快能连接到互联网。如果登录成功或已处于登录状态，程序会自动退出。

* **（可选）步骤三：设置开机自启动**
    为了实现完美的自动化体验，你可以将 `自动登录.exe` 设置为开机自启。
    1.  双击打开 `开机启动管理.bat` 
    2.  按照提示进行设置
   
### 2. 自行部署运行（适合开发者）

如果你想从源代码运行、修改或调试本项目，请遵循以下步骤。

* **环境要求**
    * Python 3.7+
    * AutoHotkey v2.0+

* **步骤一：克隆或下载仓库**
    ```bash
    git clone [https://github.com/sep-zxy/Auto-login-on-campus-network.git](https://github.com/sep-zxy/Auto-login-on-campus-network.git)
    cd Auto-login-on-campus-network
    ```

* **步骤二：安装 Python 依赖**
    本项目依赖 `playwright` 库来驱动浏览器。
    1.  安装库文件：
        ```bash
        pip install playwright
        ```
    2.  Playwright 需要安装相应的浏览器驱动。脚本默认使用 `msedge`，执行以下命令来安装它：
        ```bash
        playwright install msedge
        ```
        *你也可以执行 `playwright install` 来安装所有支持的浏览器驱动。*

* **步骤三：配置登录信息**
    你有两种方式来创建 `config.json` 配置文件：
    1.  **使用 AHK 工具**：直接运行仓库中的 `.ahk` 脚本，填写信息并保存。
    2.  **手动创建**：在项目根目录下手动创建一个名为 `config.json` 的文件，并填入以下内容（请替换为你的真实信息）：
        ```json
        {
          "username": "你的学号",
          "password": "你的密码",
          "operator_label": "巢湖学院"
        }
        ```
        *注意：`operator_label` 必须与登录页面下拉菜单中的文本完全一致。*

* **步骤四：运行登录脚本**
    打开终端或命令行，确保你在项目根目录下，然后执行：
    ```bash
    python run_login.py
    ```
    *`run_login.py` 是你的 Python 脚本文件名。*

脚本会读取 `config.json` 的内容并执行登录。你可以在终端看到 "登录成功！" 或 "已经登录，无需重复操作。" 等输出信息。
